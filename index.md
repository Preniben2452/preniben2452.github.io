## 📦 What Is mister-romm?

mister-romm is a simple client for MiSTer FPGA that connects to your own RomM server. RomM is a self-hosted game library manager. mister-romm lets you use that library directly on your MiSTer console. You can pair the app with your RomM server, sync your game catalog, search for games, and download games to your MiSTer. It is built as a single static ARM binary, which means it is distributed as one application file for the MiSTer platform.

## 🛠️ Troubleshooting Basics

- Nothing happens after launching: confirm the file was copied fully and was not interrupted partway through.
- Pairing fails: re-check the server address, the network connection on the MiSTer, and whether the RomM server is running.
- Search returns nothing: run a sync, then search again.
- A download stalls: check that the server is still reachable, then try the download once more.
- The screen looks garbled: close the app and start it again; this is usually a display refresh blip rather than a problem with your setup.
